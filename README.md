# 顶会论文深度审稿与漏洞挖掘 (Paper Review Skill) - 使用说明

## 1. 功能范围
本 Skill 旨在帮助审稿人（尤其是初入学术圈的学生助理）快速、精准地完成顶会论文的审阅工作。它不仅能帮你找出论文中的拼写错误和图表排版问题，更能教你如何**剥离深度学习黑话**，通过交叉比对实验数据（尤其是补充视频），找出“核心创新点崩塌”、“实验变量不公平”等致命伤。同时，它会自动将你尖锐的发现，转化为符合 ICRA/CVPR 等顶级会议规范的专业语言。

## 2. 目录结构
- `SKILL.md`: 核心执行规则、输入输出规范及约束条件（主文件）。
- `references/`:
  - `Review_Guidelines.md`: 常用学术黑话替换表、核心质疑切入点、排雷清单。
- `examples/`:
  - `Example_Cases.md`: 真实审稿过程中遇到的核心方法被碾压、视频背刺正文、控制变量不公平等经典案例。
- `templates/`:
  - `Review_Output_Template.md`: 包含“中文内部备忘录（不打分）”和“英文提交版”的双套输出模板。

## 3. 使用方法
1. **准备输入**：将论文 PDF 提取为文本，截图关键表格（Table）和图表。如果附带了视频，建议将展示结果的片段（如柱状图）截图。
2. **唤醒 Skill**：向模型提供 PDF 文本和截图，并输入核心 Prompt（参考 `SKILL.md` 的提示词）。
3. **对齐输出**：根据模型生成的中文初稿，核对原始数据是否准确。然后根据 `templates/` 生成给老师的备忘录和提交系统的英文版。
4. **人工把关**：最终提交前，务必根据老师的要求，确认是否删除了“裁决词（如建议拒稿）”。

## 4. 维护方式
- **迭代黑话库**：若在审稿中遇到了新的“防守型反驳”（如作者用条件单调性反驳），及时将该数学反例补充到 `references/Review_Guidelines.md` 中。
- **更新模板**：不同会议（如 CVPR vs ICRA）的审稿系统格式可能不同，若有变化，请在 `templates/Review_Output_Template.md` 中新增对应的输出格式。
- **案例积累**：遇到新的“翻车”类型（例如作者自己提供的代码跑不通），请以 `案例 4` 的形式补充到 `examples/Example_Cases.md` 中。

# 审稿意见输出模板

## 模式 A：给导师的内部参考意见（不打分）
**总体评价：**
本文提出了 [方法名] 框架，通过 [核心手段] 来指导 [解决什么问题]。[一两句肯定]。但在阅读过程中，我发现当前的实验配置存在一些不完整之处，且 [核心机制] 的增量收益未能得到充分的证明。

**主要问题（Major Concerns）：**
1. **实验控制变量未隔离（第X页 X节）**：[描述基线与本文方法的不同条件]。这导致 [后果]。
2. **核心贡献缺乏证据支持（第X页 Table X 及正文）**：[列举基线优于本文的具体数据]。作者在正文中也客观指出：[引用原话]。
3. **视频与正文实验数据不一致（视频 X:XX 处 vs 第X页 Table X）**：[描述视频数据与正文数据的差异，以及字幕原话]。请作者提供对照表说明情况。
4. **调度开销与收益不匹配（第X页）**：[列举开销数据] 与 [收益数据]。高计算成本缺乏合理的收益支撑。

**次要问题（Minor Concerns）：**
1. **正文零引用与图表错误（第X页）**：[指出拼写错误、起点不对齐、图文不符等]。
2. **排版与图文不一致**：[指出断链引用 `Fig. ??` 等]。
3. **统计指标偏差**：[指出幸存者偏差或惩罚值过高的问题]。

**给老师的话术：**
“老师，这篇论文我仔细核对了正文和视频，发现核心机制的实验对比和数据一致性上有一些明显的疑点。具体位置和数据已整理如上。基于这些证据，我觉得这篇文章的有效性不足，但具体打分还需要您把关。”

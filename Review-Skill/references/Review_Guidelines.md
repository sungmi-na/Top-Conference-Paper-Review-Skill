# 审稿知识与避坑指南

## 1. 常用学术“黑话”替换表（从尖锐到专业）
- 你骗人 -> 缺乏证据支持 (Lack of evidence)
- 你方法没用 -> 增量收益未能得到令人信服的证明 (Incremental benefit is not convincingly demonstrated)
- 你让基线吃亏了 -> 存在混淆变量 / 实验控制变量未隔离 (Confounding variables)
- 你只挑简单的场景比 -> 幸存者偏差 (Survivorship bias)
- 视频和正文不一样 -> 数据存在不一致 / 缺乏清晰的对照表 (Inconsistency)
- 你为什么不加实验 -> 目前缺乏多次重复运行的统计结果，不足以支撑其稳定性。

## 2. 核心质疑切入点
- **预测器 vs 策略**：如果作者用神经网络预测时间，基线用经验查表，这不是策略的胜利，而是预测器的胜利。要求补充“统一准入机制”的消融实验。
- **AUC 指标水份**：检查公式中未找到解时的惩罚值（如 1000）。如果数值极大，AUC 的改善往往只代表“找解快”，不代表“找到解后质量好”。
- **联合成功场景**：如果只比较双方都成功的场景，会掩盖作者在困难场景下产生的极差解。

## 3. 论文视觉与格式排雷清单
- 拼写与语病（如 "Seeds for each seed"）
- 断链引用（如 `Fig. ??`）
- 轨迹物理一致性（如候选轨迹起点未对齐全局起点）
- 图文不符（图注有“独立检查器”，但图里没画）
